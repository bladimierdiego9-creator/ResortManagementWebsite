# A&D Thysia System Icons

Custom SVG icons para sa A&D Thysia Resort Management System.

## Available Icons

1. **dashboard.svg** - Grid layout icon for Dashboard
2. **bookings.svg** - Calendar with dots icon for Bookings/Reservations
3. **calendar.svg** - Simple calendar icon for Calendar view
4. **facilities.svg** - House/building icon for Facilities
5. **payments.svg** - Credit card icon for Payments
6. **analytics.svg** - Bar chart icon for Analytics
7. **ai-concierge.svg** - Chat bubble with smile for AI Concierge
8. **attendance.svg** - Clock icon for Attendance & Payroll
9. **accounts.svg** - Multiple users icon for Account Management
10. **settings.svg** - Gear icon for System Settings
11. **audit-log.svg** - Document icon for Audit Log

## Usage

All icons use `currentColor` for stroke, so they will inherit the text color from their parent element.

### Example in HTML:
```html
<img src="/static/images/icons/dashboard.svg" alt="Dashboard" width="20" height="20">
```

### Example in CSS as background:
```css
.icon {
    background-image: url('/static/images/icons/dashboard.svg');
    background-size: contain;
    background-repeat: no-repeat;
}
```

## Icon Style
- Stroke width: 2px
- Size: 24x24 viewBox
- Style: Line/Outline icons
- Color: Inherits from parent (currentColor)
